# Resources

Every source below is either first-party (Microsoft Learn or GitHub) or a well-maintained reference. The two Microsoft Learn learning paths together cover the full skills-measured outline and are the single most efficient study path.

## Start here (official, exam-specific)

| Resource | Why it matters |
| --- | --- |
| [Exam GH-300 / GitHub Copilot certification page](https://learn.microsoft.com/en-us/credentials/certifications/github-copilot/) | Registration, exam policy, level, and the scheduling button. Confirms the exam is generally available, intermediate, and English-language. |
| [GH-300 study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/gh-300) | The authoritative skills-measured outline (as of 7 August 2026). Treat this as the checklist the whole sprint is graded against. |
| [Exam sandbox](https://aka.ms/examdemo) | The exact question interface, including interactive question types. Run it before exam day so the format is not a surprise. |
| [Practice assessment](https://learn.microsoft.com/en-us/credentials/certifications/github-copilot/practice/assessment) | A free official practice test that mirrors the exam style. Use it as the Day 10 mock if a longer bank is not available. |

| Learning path | Maps to |

## Two logistics notes worth acting on early

1. Register with a personal Microsoft account, not a work or school account. Records tied to an organisational account can be lost if the holder leaves the organisation.
2. Run the online proctoring system pre-check on the actual machine and network to be used, before booking, if taking the exam online rather than at a test centre.
